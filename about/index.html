About PS/2 Toolbox

IBM hardware lookups built from public catalogues and technical references.

MCA ADF Lookup

MCA ADF Lookup brings together public records for Micro Channel adapter files, system boards and companion files. The ID lookups view also includes historical entries without a linked ADF.

Reading the results

Expand a grouped ID to compare variants from different sources. Adapter names and file versions come from the ADF header where available. Versions marked Catalogue come from a source listing. A dash indicates an unrecorded value.

Memory Lookup

The lookup joins IBM’s model and part-number tables and adds OEM markings and selected model-specific references. Rows without a machine or card listing can help identify a module. Check the cited model documentation for installation rules and maximum capacity.

RS/6000 coverage currently includes the 7011-250 Kingston entries. The RS/6000 memory matrix and IBM service guide below cover additional machines.

Use the 72-pin SIMM guide to decode presence-detect patterns. The model and planar references cover board revisions and connectors.
