# PS/2 Toolbox

Two offline-capable IBM hardware lookups from public references.

- [Toolbox home](https://niklasrichardson.github.io/ps2-toolbox/) introduces both tools.
- [MCA ADF Lookup](https://niklasrichardson.github.io/ps2-toolbox/mca-adf-lookup.html) searches adapter descriptions, variants, planar IDs and companion files.
- [Memory Lookup](https://niklasrichardson.github.io/ps2-toolbox/memory-lookup.html) joins the IBM EPRM machine and part-number tables with OEM markings and model-specific memory references.

Keep the three HTML files together to browse offline. To publish an update, regenerate the website from PS/2 Toolbox and replace the HTML on the `main` branch. Each page embeds Carbon styles and IBM Plex Sans.
