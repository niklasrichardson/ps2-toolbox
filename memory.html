About the memory lookup

The lookup joins IBM’s model and part-number tables and adds OEM markings and selected model-specific references. Rows without a machine or card listing can help identify a module. Check the cited model documentation for installation rules and maximum capacity.

RS/6000 coverage currently includes the 7011-250 Kingston entries. The RS/6000 memory matrix and IBM service guide below cover additional machines.
